# User Stories

Project: HireStack

Version: 1.0

Status: Final

---

# Introduction

User stories describe the platform from the user's perspective.

Each story follows the format:

As a <role>,
I want <goal>,
so that <benefit>.

These stories drive UI design, API development, and testing.

---

# Candidate User Stories

## Registration

As a candidate,
I want to create an account,
so that I can apply for jobs.

---

As a candidate,
I want to verify my email,
so that my account is secure.

---

As a candidate,
I want to log in securely,
so that I can access my dashboard.

---

## Profile

As a candidate,
I want to update my profile,
so recruiters can view accurate information.

---

As a candidate,
I want to upload my resume,
so recruiters can evaluate my application.

---

## Job Search

As a candidate,
I want to browse available jobs,
so I can discover opportunities.

---

As a candidate,
I want to search jobs by keyword,
so I can quickly find relevant positions.

---

As a candidate,
I want to filter jobs,
so I only see jobs matching my preferences.

---

## Applications

As a candidate,
I want to apply for a job,
so recruiters can review my application.

---

As a candidate,
I want to track my application status,
so I know where I stand.

---

# Recruiter User Stories

## Authentication

As a recruiter,
I want to log in securely,
so I can manage hiring.

---

## Job Management

As a recruiter,
I want to create job postings,
so candidates can apply.

---

As a recruiter,
I want to edit jobs,
so information stays updated.

---

As a recruiter,
I want to close job postings,
so applications stop after hiring.

---

## Candidate Management

As a recruiter,
I want to review applications,
so I can evaluate candidates.

---

As a recruiter,
I want to download resumes,
so I can perform detailed reviews.

---

As a recruiter,
I want to change application status,
so candidates know their progress.

---

## Dashboard

As a recruiter,
I want to view recruitment statistics,
so I can monitor hiring activity.

---

# Administrator User Stories

As an administrator,
I want to create recruiter accounts,
so companies can start hiring.

---

As an administrator,
I want to manage users,
so the platform remains secure.

---

As an administrator,
I want to deactivate accounts,
so unauthorized users cannot access the system.

---

As an administrator,
I want to monitor platform analytics,
so I understand platform usage.

---

# General User Stories

As a user,
I want to reset my password,
so I can recover my account.

---

As a user,
I want responsive pages,
so I can use the platform on any device.

---

As a user,
I want fast page loading,
so my experience remains smooth.
