# HireStack v1.0.0 Release Notes

**Release Version:** v1.0.0

**Status:** Stable Release

**Release Type:** Major Release

**Project:** HireStack – Applicant Tracking System (ATS)

---

# Overview

Version **1.0.0** marks the first stable backend release of HireStack. This release establishes the core foundation of the Applicant Tracking System by providing secure authentication, company and recruiter management, job lifecycle management, candidate processing, interview workflows, hiring pipeline management, offer handling, and supporting infrastructure.

This version is intended as the baseline for future frontend integration and feature expansion.
